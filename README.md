# Student Portfolio Template

A reusable portfolio website for creative students. The original layout, styling, and animations are preserved. Students personalize the website through **one file**: `student-info.js`.

## Folder structure

```text
student-portfolio-template/
├── index.html             # Website structure — leave unchanged
├── style.css              # Design and Student Guide styling — leave unchanged
├── script.js              # Website interactions — leave unchanged
├── student-info.js        # EDIT THIS FILE for your portfolio
├── student-guide.js       # Visual guide — leave unchanged
├── README.md
└── assets/                # Put your own photos and thumbnails here
```

## Start here

1. Open this folder in VS Code.
2. Open `student-info.js`.
3. Edit the information near the top of the file, inside quotation marks. Do not change the application code below the comment `APPLY THE INFORMATION ABOVE`.
4. Put your own image files in `assets/`. Keep the filenames in the configuration matched to the actual files.
5. Save the file and refresh the browser.
6. Click **Student Guide: OFF** at the bottom-right of the website to turn on visual labels.

## What to change

- Your full name, short name, profession, page title, and availability
- Main headline and introduction
- Profile photo (`assets/profile.jpg`)
- Honest experience/project statistics
- About section and skills
- Featured YouTube video ID
- Recent projects and long-form projects: title, category, thumbnail, video ID
- Services and descriptions
- Email, WhatsApp number, and social profile URLs

## Image filenames

The starter configuration expects these files. Replace the image contents with your own images and keep the same filenames, or update the corresponding paths in `student-info.js`.

- `assets/profile.jpg`
- `assets/thumbnail1.jpg` through `assets/thumbnail5.jpg`
- `assets/videothumbnail1.jpg` through `assets/videothumbnail4.jpg`

The uploaded project did not include the original `assets` folder, so add/copy your existing asset files into this folder before previewing.

## YouTube video IDs

For `https://www.youtube.com/watch?v=AbCd1234567`, the ID is `AbCd1234567`. For a Shorts URL, use the text after `/shorts/`. Replace every `YOUR_...` example with a real ID.

## Preview in VS Code

Recommended: install the **Live Server** extension, right-click `index.html`, then choose **Open with Live Server**. Alternatively, double-click `index.html` to open it in a browser. After editing, save and refresh.

## Important rules

- Edit only `student-info.js` unless your instructor asks you to do otherwise.
- Do not delete the image files or rename them without updating their paths.
- Do not publish placeholder contact information. Replace all sample email, phone, social, and video values before publishing.
- Do not claim experience or project counts that are not accurate.
- Each student should publish their own copy of the project.
